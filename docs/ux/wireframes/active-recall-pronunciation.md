```text
┌─────────────────────────────────────┐
│ Đến hạn ôn · Câu 1                  │
│                  你好               │
│                nǐ hǎo               │
│ [A. cảm ơn]     [B. xin chào]       │
│ [C. tạm biệt]   [D. học sinh]       │

│ ✓ Chính xác / Chưa đúng: xin chào   │

```
