# Wireframe: Học tiếp bài kế

```text
┌──────────────────────────────────────────┐
│                   ✓                      │
│           Hoàn thành Bài 1               │
│  Tiến độ và từ mới đã được lưu.          │
│                                          │
│  [ Học tiếp Bài 2 → ]  [ Về lộ trình ]  │
└──────────────────────────────────────────┘
```

Sau Bài 5, nút chính đổi thành `Làm checkpoint →`.

## Trạng thái

- Chưa hoàn thành: hiển thị hoạt động phát âm và nút hoàn thành.
- Đã hoàn thành Bài 1–4: xác nhận, học tiếp, về lộ trình.
- Đã hoàn thành Bài 5: xác nhận, làm checkpoint, về lộ trình.
